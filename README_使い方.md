# そらたび（SORATABI）― ホーム画面を再現した操作可能なアプリ試作版

## 今回できたもの

提供された「そらたび」の丸い写真ロゴと海辺の写真を利用して、iPhoneでの見た目を優先した旅行・宿泊検索アプリを制作しました。

- ホーム：ヒーロー写真／検索バー／海・温泉・絶景・体験などの絞り込み／宿3列カード／周辺観光5列カード／旅行特集
- 宿検索：宿名・エリア・タグのキーワード検索（複数語 AND）／テーマ絞り込み／名前順・参考料金順の並び替え
- 宿名をタップ：宿の詳細と「その宿の近くにある観光・体験」
- 観光カードをタップ：観光・体験の詳細と「そのスポットに近い宿」への逆引き
- お気に入り：端末のブラウザへ保存（同じブラウザで保持）
- フッター：ホーム／宿／周辺／お気に入り／マイページ
- GitHub Pagesに対応。ホーム画面への追加でiPhoneアプリ風に表示できます（PWA）。

**大切：現時点で楽天トラベルのデータ取得・リアルタイム予約・価格連携は未実装です。** サンプル宿名、レビュー、料金、距離は実データではありません。操作・デザイン確認用の架空サンプルと明示しています。「楽天トラベル掲載確認済み」バッジは実際の確認済みデータを導入した場合だけ表示されます。サンプルの予約ボタンは楽天トラベルのトップページを開くだけです。

## GitHub Pagesにアップロード

このZIPファイルを解凍して、中にある **index.html、assetsフォルダ、dataフォルダ、manifest.webmanifest、service-worker.js** をGitHubリポジトリの一番上（公開する場所）に入れてください。`assets` や `data` はフォルダ構造を保ってください。GitHub PagesがONになったらリポジトリのPages URLをSafariで開けます。

iPhoneだけで作業する場合は、ZIPファイルを「ファイル」アプリでタップして解凍し、GitHubに一つずつファイルをアップロードしてください。大量にアップロードしづらい場合は、別途同梱しない **soratabi_onefile_index.html** をGitHubの `index.html` に名前変更して登録すると、画像も含む1ファイルだけでデザインと操作を確認できます（こちらはPWAキャッシュを持ちません）。

## 将来、宿泊実データを追加する場合

`data/places.json` に掲載確認済みの宿とその宿から近い観光地・体験施設を入れます。テンプレートは現在空になっています。

データ構造の例（**記載内容は説明のための架空IDです。URLも実在する施設のリンクに差し替えてください**）：

```json
{
  "hotels": [
    {
      "id": "hotel-001", "name": "正式な宿泊施設名", "area": "都道府県・市町村",
      "prefecture": "都道府県", "description": "確認済みの紹介文",
      "verifiedRakuten": true,
      "rakutenUrl": "https://travel.rakuten.co.jp/（実際の当該施設ページのURL）",
      "image": "hotel1.jpg", "tags": ["海", "絶景"],
      "price": null, "rating": null, "reviews": null
    }
  ],
  "spots": [
    {
      "id": "spot-001", "name": "正式な観光地・体験施設名",
      "type": "観光スポット", "description": "確認済みの紹介文",
      "image": "attraction1.jpg", "tags": ["海", "絶景"],
      "links": [{"hotelId": "hotel-001", "distance": 1.2}]
    }
  ]
}
```

**掲載ルール**

1. 宿泊施設は `verifiedRakuten:true`、有効な `https://travel.rakuten.co.jp/...` のURL、名称とIDが揃ったものだけアプリの実データに切り替わります。
2. 観光施設は、前項の宿と `links[].hotelId` で結びついている施設のみが表示されます。
3. `distance` は宿とスポット間の距離（km）。実データでは住所・座標からの算出など正確な根拠を用意してください。現段階で自動計測はしていません。
4. 宿が1件も実データにない場合はデザイン確認用サンプルのままです。本番公開前には実データ導入とサンプルの非表示設定をおすすめします。
5. `image` は assetsフォルダに存在する画像ファイル名です。実在施設の写真は使用許諾・規約を確認し、サンプル写真を実施設写真として流用しないでください。

## 楽天トラベル連携に関する注意点

実際の宿検索・最新価格・空室の扱いは、楽天トラベルの提供するAPI、アフィリエイト制度、利用規約等の確認が必要です。宿の掲載・画像・詳細情報を無断で大量取得する仕組みは入れていません。現時点の予約ボタンは楽天トラベルを別タブで開きます。成果報酬計測は未設定です。

## ファイルについて

- `index.html`：アプリ本体
- `assets/`：ロゴ・トップ画像・画像素材・アイコン
- `data/places.json`：楽天トラベル掲載確認済みデータ（現在は空）
- `manifest.webmanifest` / `service-worker.js`：PWA用。HTTPS の GitHub Pages で有効

表示中に画像が表示されないときは、`index.html` の横に `assets` フォルダがあるか確認してください。
